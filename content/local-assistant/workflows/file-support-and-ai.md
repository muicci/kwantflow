title: Files, preview, and AI use
kind: help
summary: Not every file behaves the same way in review, preview, or AI drafting, so the assistant should explain support in outcome terms.
keywords: file support, preview support, ai support, supported files, unsupported files, upload file
---

Different file types can be supported in different ways.

Some files are mainly for review and preview, while others can also contribute evidence to AI drafting. If a file is not used by AI, that should be explained clearly rather than guessed.

If a user asks whether a file is supported, answer in practical terms:

- can it be uploaded
- can it be reviewed in the app
- can it contribute to AI drafting

Keep the answer focused on what the user can do, not on internal transport or parsing details.
