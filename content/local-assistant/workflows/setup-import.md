Setup import is for shared workspace setup data, not for live RFQ or estimate jobs.

Users can use setup import to seed reference data such as:

- companies
- materials
- labour rates
- equipment rates
- subcontract rates
- cost presets
- estimate templates
- classification systems and cost codes

If a user asks whether setup import is for project jobs, explain that it is for workspace setup records rather than RFQs, assets, files, or estimates.
