An asset is the estimating bundle for a scope or work package inside an RFQ.

Assets let users group one or more RFQ files into a practical estimating unit. That keeps the estimating workflow separate when one RFQ contains multiple parts, packages, or trades.

Each asset can hold one working estimate. The estimate is made of takeoff items and cost components, and it stays local until the user reviews and saves it.

When users ask how to keep work organised, the answer is:

1. start in the RFQ
2. group related files into an asset
3. build or review the estimate inside that asset
