Files belong to the project first. They appear in the **In Review** list on the left side of your screen.

This lets you review incoming job material before deciding how it should be grouped for estimating.

To group files into an asset:

1. Select one or more files in the **In Review** list using the checkboxes.
2. Click the **Create Asset** button.
3. Enter a name for the new asset.
4. The files move to the **Assets** list on the right.

To start estimating, click **Open asset estimate** on the new asset.

You can view your files in a grid or a list. Use the **Grid view** and **List view** buttons to switch between them.

If you need to change how files are grouped, click the **More actions** button on an asset and select **Ungroup Asset**. This will delete the asset's estimate and return the files to your review list. To remove a single file from an asset, expand the asset and click **Return file to review** next to the file name.
