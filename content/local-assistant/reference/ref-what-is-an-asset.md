# What is an Asset?

In Kwantflow, an **Asset** is a collection of files that represent a single physical part, assembly, or item you need to estimate. Sometimes, this is also referred to as a "Scope Item".

When a customer provides multiple files for a single job—such as a 3D model, a PDF drawing, and a material specification document—these files often relate to the same physical object. By grouping these related files into an Asset, you can estimate them together as one complete item.

## How Assets work

- **Estimating:** Every Asset has its own dedicated estimate. When you open an Asset, you build the material, labour, and equipment costs required to produce that specific item.
- **Grouping files:** You can select one or more files from your project's review list and use **Create Asset** to group them.
- **Naming:** You can give each Asset a clear name, such as "Bracket Assembly" or "Steel Frame", to make it easily identifiable in your quote.
- **Ungrouping:** If you need to separate the files, you can choose **Ungroup Asset**. This returns the files to the review list, but it will also delete any estimate data you have built for that Asset.

## Why use Assets?

Organising your project into Assets makes estimating complex quotes much easier. Instead of working through a long list of disconnected files, breaking the project down into logical items allows you to build more accurate estimates and generate clearer quotes for your customers.
