Kwantflow application code is distributed under GNU GPL version 3 only. See `LICENSE`.
Earlier application attribution, `Copyright (c) 2026 Caliper`, is retained verbatim in
`third-party/licenses/kwantflow-prior-mit.txt`. Third-party components retain their
own licenses and notices. The app license does not replace their licenses.

Actual license texts are included under `third-party/licenses/`. The exact npm and
Cargo versions, package metadata, copied notice hashes, and unresolved collection
gaps are recorded in `third-party/dependency-inventory.json`. This inventory covers
the installed npm production dependency closure, Svelte/Kit client runtime and
Tailwind base CSS with their dependencies, and registry crates in Cargo.lock.
It is not a complete binary SBOM and does not certify legal compatibility.
Some upstream packages publish only a license identifier and omit a standalone
license file. Those cases are listed separately in `declared-license-evidence.json`,
with the unchanged upstream declaration and canonical SPDX license text. Canonical
template text is license terms, not an invented copyright notice for the package.
Preserve the actual copyright notices in the corresponding source distribution.

## Native runtime and optional model download

Native input pins are recorded in `native-inputs.json` and the Windows runtime
contract. Native notices are under `third-party/licenses/native/`. PDFium archive
notices cover its bundled components and are included separately from the
permissive `pdfium-render` Rust wrapper. LiteRT-LM 0.16.0 is Apache 2.0; native
transitive components require their own notices and exact source review.
The official LiteRT-LM 0.16.0 Apple SPDX and third-party notice assets are included,
with 141 extracted component texts, in the native notice tree. Their original
digests and acquired source archives are recorded in `native-source-manifest.json`.

The Windows build does not ship the DirectX Shader Compiler (DXC/DXIL) helpers,
because `dxil.dll` is distributed under a restrictive Microsoft licence. GPU
acceleration on Windows uses the operating system's shader compiler when
available; otherwise Local AI runs on the CPU.

Local AI uses the pinned Gemma 4 E4B LiteRT model defined in
`src-tauri/local-ai-runtime-manifest.json`. Its pinned upstream model card declares
Apache 2.0. Model weights are downloaded separately and verified before local
use; the installer does not contain the weights.

macOS WebKit and Windows WebView2 are operating-system/vendor runtimes. Their
presence does not make them open-source Kwantflow dependencies. WebView2 or Visual
C++ vendor installers remain subject to Microsoft's redistribution terms; those
rights must be established independently of the app's GPL license.

## Corresponding source

The complete corresponding source for a release is the matching release tag of
the public Kwantflow Git repository: application source, build scripts,
lockfiles, user documentation, this notice file, `third-party/SOURCE_BUILD.md`,
the native source recipes and patches, and the license manifests that pin every
upstream source archive by URL, revision and SHA-256. Running
`pnpm third-party:sources:prepare` acquires those pinned archives and verifies
their hashes. `pnpm distribution:source` can additionally export a self-contained
archive that bundles the acquired upstream sources with the application source.

`third-party/manifest.json` and `third-party/native-source-manifest.json` also
record a `distributionReview` status with the open items that remain for a
byte-exact rebuild proof of every native component. Hash and source collection
checks do not prove an executable rebuild. Those records are kept honest and
are not a release gate; they describe what has and has not been reproduced.
Exact legacy font metrics are not implied by substituting open fonts.
